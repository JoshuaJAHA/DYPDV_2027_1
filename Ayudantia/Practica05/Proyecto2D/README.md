# Practica 5 

## Descripcion
En esta practica se implemento un enemigo patrullero tipo Goomba y la estructura basica de herencia mediante la superclase Personaje.

## Instrucciones de Uso
1. Abrir la escena principal en Assets/Scenes/SampleScene.unity.
2. Presionar Play para iniciar la prueba.
3. Usar las teclas A y D para mover al jugador y la barra espaciadora para saltar.
