# Practica 6 - Proyectiles y Plataformas

## Descripcion
En esta practica se implemento un sistema para el jugador y elementos dinamicos de escenario:
- Sistema de disparo mediante proyectiles prefabs que heredan la velocidad horizontal del jugador.
- Deteccion de colisiones del proyectil con enemigos, haciendoles daño hasta eliminarlos
- Plataformas moviles que patrullan entre dos puntos y transportan al jugador 
- Animacion del proyectil al disparar.

## Controles
- A / D o Flechas: Mover al jugador.
- Espacio: Saltar 
- Ctrl izquierdo: Disparar proyectil.

## Instrucciones de Uso
1. Abrir la escena 
2. Presionar Play en el editor de Unity.
